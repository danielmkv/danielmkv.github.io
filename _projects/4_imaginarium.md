An [open-source](https://github.com/corrze/Imaginarium) AI-powered interactive storytelling platform that creates choose-your-own-adventure stories for children ages 6-12. Built for Dubhacks '25, this full-stack web application combines creative AI generation with a kid-friendly interface to encourage reading and imagination.

**Key Features:**
- Real-time AI story generation using Google Gemini 2.0 for dynamic, age-appropriate narratives
- Interactive choose-your-own-adventure gameplay with multi-page navigation
- Firebase Authentication with role management for child and parent accounts
- Tiered subscription system with Stripe payment integration
- Responsive, mobile-first design with smooth animations

**Technical Implementation:**
- Built RESTful API backend with Flask and integrated Google Gemini AI for intelligent narrative generation
- Developed modular JavaScript architecture with separate controllers for UI rendering, story management, and page logic
- Implemented Firebase Firestore for data persistence and user management
- Created payment processing system for premium membership tiers

**Timeline:** 2025

**Type:** Hackathon Project (Dubhacks '25)

**Technologies:** Python, Flask, JavaScript, Firebase, Google Gemini AI, Stripe API, HTML/CSS
